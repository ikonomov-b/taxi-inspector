# Security policy

Taxi Inspector is an offline application and should not contain credentials, API keys, signing keys, or personal data in source control.

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Use GitHub's private vulnerability reporting feature for this repository, or contact the repository owner privately through GitHub with reproduction details and the affected commit or version.

Include the impact, reproduction steps, and any suggested mitigation. Do not include real user data or private keys in a report.
